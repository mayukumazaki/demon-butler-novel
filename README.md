# พ่อบ้านจอมมาร

คลังนิยายฉบับอ่านสาธารณะ จากชุดไฟล์ 1–2100 รวมเนื้อหาจริง **2,022 ส่วน** มีฉบับเกลาครบทุกส่วน พร้อมค้นหาและย้อนอ่านฉากต้นทาง

## เปิดอ่าน

**[อ่านนิยายบนเว็บไซต์](https://mayukumazaki.github.io/demon-butler-novel/)**

- อ่านได้โดยไม่ต้องมีบัญชี GitHub
- เลือกชุดไฟล์ ค้นข้อความ และปรับขนาดตัวอักษรได้
- เปิดฉบับเกลา หรือเทียบต้นฉบับในบทที่รองรับ
- บางส่วนเป็นฉบับดัดแปลงเหมาะวัย มีป้ายบอกแยกไว้
- เลขช่วงชื่อไฟล์ไม่ใช่จำนวนบทจริง มีการเริ่มเลขใหม่และหัวบทซ้ำต่างฉบับ

## ไฟล์และการตรวจสอบ

`site.zip` คือเว็บไซต์พร้อมข้อมูลนิยายทั้งหมด ดาวน์โหลดแล้วแตกไฟล์เพื่อเก็บสำรองได้ เว็บต้องเปิดผ่าน HTTP server เพื่อโหลดข้อมูล JSON

`content-manifest.json` บันทึกรายการไฟล์ จำนวนส่วน และ SHA-256 สำหรับตรวจความครบถ้วน

การเผยแพร่ครั้งนี้มีเฉพาะเนื้อหาฉบับอ่าน ไม่รวมแชทส่วนตัว เอกสารวางแผน คีย์ API และข้อมูลเชื่อมต่อบัญชี

## ลิขสิทธิ์

นิยายและภาพอ้างอิงเป็นผลงานของผู้เขียน สงวนลิขสิทธิ์ การเปิดให้อ่านไม่ได้เป็นการอนุญาตให้นำไปเผยแพร่ซ้ำ ดัดแปลง หรือใช้เชิงพาณิชย์โดยอัตโนมัติ
